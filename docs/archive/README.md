# Archive

Designs set aside at the reset of 2026-11-23 (vision §5, decision `core-and-line`). Physa now defends a core and leaves workflow to teams, and these were written for the old Shape Up flow or for parts not yet built. They are reference, not settled: the parts are being designed again with the people now joining, and anything taken from here is settled again first.

- `architecture/04-harness-interface.md`: how harnesses plug into the engine (plan step 6–7).
- `architecture/05-earned-release-and-strength.md`: flags, signals and the strength model. Engineering evidence from it is built (03 §21); the rest is not. Strength itself stays core (vision §5, item 1).
- `architecture/06-views-and-the-network.md`: Needs you, the network view and the phone web.
- `architecture/07-records-and-verification.md`: what Physa records about work and how it is verified. Slice records are built (01).
- `design/`: mockups for the views.
- `plan.md`: the build plan as it stood, steps 0–11.

The decisions and rules these designs produced are still in the map, each citing its file here.
