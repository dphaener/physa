# Slices

Slices cover how an agent gets the product knowledge its task needs, in one call, before it starts: the index of capabilities and the slice built from it. Promises, overviews, rules and the headings of decisions and questions are always in a slice, the agent takes the rest by slug, and the same request gives the same slice.
