Recommendation

A4, the grown Plasmodium, as the network view; Strands on each capability's page

  1. The network view is A4: A3's layout drawn as one fused, tapering body. A1's structure (each idea grows from one capability, each capability from the product, fixed angles) in the organism's body: one translucent sheet, meandering veins, growing fronts, slime trails for lessons. At rest only thickness and kind compete for attention; a capability's food dots and loops (A2's detail) appear when it is tapped. Still plain geometry the Go core can draw as SVG with no script.
  2. Each capability's page uses C, Strands (the owner's call): that capability's tube over time, with its ideas joining, withering and growing.
  3. B, the Mesh, waits until the owner decides whether capabilities connect to each other.
