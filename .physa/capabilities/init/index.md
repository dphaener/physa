# Init

Init maps a repo that has no map: it gathers the sources, where fixed rules find the usual docs and one read-only agent names more beside them, proposes the capabilities, recovers each one from its history and docs, and writes the map to a `physa/init` PR. A new codebase gets a short round of questions instead.
